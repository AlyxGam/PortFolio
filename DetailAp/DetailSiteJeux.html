Game Conseil

Période : 18 Janvier - 6 Mai 2024

Description :

Ce projet a permis de faire du php avec une base donnée PhPMyAdmin et apprendre a manipuler une base de donnée via du PHP

Dans ce projet on a acquis plusieurs compétences notamment Bootstrap un framework CSS qui à été la première phase du projet. C'est un projet séparer en deux phase, la première phase était la contruction du site et la création de plusieur page commune pour différentes catégorie comme par exemple pour les personnages ou bien ou les détails de chaque personnage.

Ensuite la deuxième phase consiste à implémenter le php et une base de donnée pour rendre le site dynamique. Le php m'a permis notamment d'ajouter certaine fonctionnalité comme ajouter/modifier/supprimer des personnages via un pannel administrateur.

Outils utilisés :

  • Php
  • Css
  • MySql
  • BootStrap

Stage chez Silentsys

Description du stage

Ce projet consistait à améliorer un programme Python permettant de communiquer avec les appareils de la marque Pico.

La première étape a été d'analyser le programme existant pour identifier les améliorations nécessaires, en comprenant les fonctionnalités actuelles et les spécificités des appareils Pico.

La seconde étape a porté sur la mise en œuvre des améliorations pour optimiser le code et les interfaces, les rendant plus performants et fiables. Ce travail a permis d'approfondir nos compétences en Python, notamment en structuration de code et en gestion des interactions logiciel-matériel.

Outils utilisés :

  • Python
